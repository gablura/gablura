# Focura

A hyper-productivity platform that combines task management, focus sessions, burnout prevention, wellness tracking, AI assistance, and billing into one integrated platform.

## Why it exists

Developers juggle multiple tools for tasks, focus, wellness, and team management. Focura combines these into a single platform designed specifically for how developers actually work.

## Features

- **Task management** — Projects, workspaces, and team collaboration
- **Focus sessions** — Pomodoro-style focus with distraction blocking
- **Burnout prevention** — Activity tracking with smart warnings
- **Wellness tracking** — Monitor work-life balance metrics
- **AI assistance** — Smart suggestions and automation
- **Billing** — Integrated payment with Lemon Squeezy

## Tech stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend:** Express.js, TypeScript
- **Database:** PostgreSQL with Prisma ORM
- **Cache:** Redis with BullMQ for job queues
- **AI:** Google Gemini
- **Payments:** Lemon Squeezy
